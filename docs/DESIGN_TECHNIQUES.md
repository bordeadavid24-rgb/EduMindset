# How the V4 page is built

These techniques give the current red and charcoal notebook, comic, and photographic collage design its structure. Each has a concrete job here. This explains the implementation; it does not certify final performance, accessibility, or real-device tests.

| Technique | What it means here | What it does for this page |
| --- | --- | --- |
| Authored invitation | The welcome, motivation, and founder letter use the supplied first-person account. | Makes the invitation come from a named person through his own words, without adding personality claims, praise, or invented endorsements. |
| Grid composition | The desktop opening uses twelve columns and two rows. The large scene crosses both rows while the title and welcome occupy related areas. | Connects photograph, proposition, and action in one composition instead of a standard image-and-text card pair. |
| Alpha cutout | Transparency follows the outline of Alex, his microscope, and the table base. | The real subject can share the page's background without keeping the full rectangular laboratory photograph. |
| Photographic compositing and layering | The source-derived cutout sits over a cut-paper red plane, a halftone patch, and an original orbit stroke. | Connects the real subject to the page's notebook world. These layers are editorial artwork, not new photographic evidence or a different laboratory setting. |
| Original SVG line drawing | Small book/bulb, pencil, question, orbit, and dialogue drawings are vector paths authored for the site. Rounded caps and joins share a mostly 2.4-width line grammar. | Supplies a school-notebook character without downloading stock illustrations or adding a drawing library. These are new digital drawings, not Alex's own sketches. |
| Cut-paper contours | CSS `clip-path` polygons give selected fields short irregular edges. | The red backing, programme boundary, and notes suggest assembled paper. The irregularity belongs to the surrounding shape rather than the text itself. |
| Squared paper and halftone | CSS linear gradients draw the grid; radial gradients draw repeating dots. | Introduces notebook ruling and a printed-comic texture without a new raster image. The hero halftone is removed on mobile to reduce visual density. |
| Photo-print collage | Light borders, a little padding, small rotations, and decorative tape strips frame the supplied portrait and other images. | Makes the photos feel assembled into one publication. Tape and paper are CSS treatments, not claimed as Alex's personal possessions. |
| Comic callout | An original outlined question bubble sits near the hero scene, with a small book/bulb nearby. | Adds the visual language of curiosity. The bubble is decorative, not an attributed quote or an essential instruction. |
| Draw-on stroke | The red circle around the main word uses SVG dash offset to reveal a single path once on desktop. | Briefly directs attention to the page's question. It is disabled with reduced motion, and the headline and photograph are immediately visible. |
| Art-directed crops | The portrait, classroom, and auditorium photographs use intentional `object-fit` and `object-position` choices. Mobile changes image proportions and scale. | Keeps the face and useful context visible when a desktop image becomes a narrow mobile layout. The founder portrait supports a reading moment rather than dominating an entire screen; paper backing sits outside the crop. |
| Palette roles | Brighter brand red belongs to artwork; darker red belongs to small controls and links. Charcoal and warm neutrals carry reading. | Keeps the original red/black identity while giving interactive text a more legible colour. The dark programme has light text, and its recall exercise returns to a light note field. |
| Typographic hierarchy | One local Bricolage Grotesque variable family supplies headlines, body, captions, and controls. Size, weight, spacing, and optical sizing distinguish jobs. | A large proposition, quieter personal copy, and clear workshop names create a reading order without several competing fonts. Romanian diacritics remain part of the type system. |
| Open-letter layout | The founder's compact portrait and factual qualifications sit beside a wider first-person reading column, with a greeting, short quotation, and signoff. | Adds personal authorship without a profile card, credentials wall, or fabricated signature. |
| Information architecture | V4 orders the page as invitation, founder letter, working programme, project ideas, UnitED, resources, and contact. | Explains who is inviting the visitor, then shows what can be explored. The recall example belongs to Learning Skills, so the demonstration and its workshop context are connected. |
| Asymmetric grouping | Intelligent learning gets a squared-paper note and book drawing; independent thinking has an open underlined heading; personal development sits on a tinted paper shape. | Different roles receive different compositions within one palette. The leading idea gets more space, while mobile restores a clear stack. |
| Microlearning | A small optional activity teaches one idea inside the programme. | Gives visitors a sample of participation without a sign-up gate or long lesson. |
| Active recall, or reamintire activă | Read three words, hide them, try to retrieve them from memory, then reveal and compare. | Demonstrates the method before explaining its name. There is no grade, timer, diagnosis, or promise about an individual's results. |
| Comic sequencing and a step indicator | A real ordered list labels reading, recalling, and checking. JavaScript updates `aria-current="step"`, border, weight, and background to show the current stage. | Makes the exercise sequence visible and exposes the active step to assistive technology. Reset returns both the task and the indicator to reading. It is not a grade or a timer. |
| Progressive disclosure | Native expandable sections reveal the full detail when requested. | Keeps the programme easy to scan while retaining the complete supplied topic bullets and longer project story. Learning Skills starts open; links can open a contained exercise or another topic. |
| Mobile reflow | Desktop regions change structure instead of simply shrinking. The hero has an explicit phone sequence; the portrait sits beside the identity block; the programme becomes one column. | Preserves readable copy, visible actions, the whole face and instrument, and a useful reading order. Peripheral drawings shrink; hero halftone is hidden on mobile, and the workshop sketch is hidden on the narrowest phones. Secondary classroom context and QR are hidden while relevant text and Instagram remain. |
| Touch and safe-area design | Controls have usable hit areas, input text stays 16px, hover decoration is limited to fine-pointer devices, and CSS reads safe-area insets. | Supports touch without hover-only information and allows spacing around screen cutouts and the home indicator. Real-device behavior still needs inspection. |
| Responsive pictures | `picture` chooses a format or media branch; `srcset` lists widths; `sizes` describes the expected displayed width. | Lets the browser choose a suitable hero derivative and avoids sending the largest image to every phone. The smaller founder portrait has its own size hints. |
| AVIF and WebP tradeoff | The hero prefers AVIF on desktop and WebP on mobile, with WebP fallback. Both support transparency. | Balances image-transfer size against decoding work. AVIF may save bytes; decoding costs vary by image and device. The mobile WebP choice is specific to this project, not a universal rule. |
| Preload and lazy loading | Media-specific preloads prioritise the hero; lower photographs and QR use lazy loading. Local font assets are also preloaded. | Directs early requests toward the opening scene and typography rather than loading every photograph at once. Preload hints should match actual layout and CSS use. |
| Layout reservation and CLS | Image dimensions and aspect ratios reserve space. The recall stage keeps a minimum height while words change. | Reduces unexpected movement during loading or interaction. CLS means cumulative layout shift; this guide does not claim a final score. |
| Local variable fonts | The font is served with the site, and a variable face covers a range of weights. Automatic optical sizing adapts its drawing to text size. | Keeps a consistent voice for display and body, covers Romanian glyphs, and avoids an additional font family or external font stylesheet. |
| Progressive enhancement | Content and native disclosures work as HTML first. JavaScript adds recall states, theme selection, menu convenience, deep-link opening, and email preparation. | The site remains useful when script fails. A no-script explanation lets visitors try the recall idea manually. |
| Keyboard and reduced motion | Native controls retain keyboard behavior and visible focus. Escape dismisses compact navigation. Reduced-motion preference removes displacement and smooth scrolling. | Lets visitors use the page without a mouse and without depending on decorative motion. |
| Honest email handoff | The form prepares an addressed message for the visitor's email app and can copy it instead. | Explains the actual action, handles long messages, and never pretends that preparing a draft confirms sending or delivery. |

The hero is an **AI-assisted, source-derived cutout**, not an untouched original photograph. The edit and exact prompt remain at `assets/derived/alex-laborator-cutout-v2.png` and `assets/derived/alex-laborator-cutout-v2.prompt.txt`. Responsive files are built by `scripts/prepare-v2-assets.mjs`; those filenames describe asset history, not the current design version. The portrait, classroom, and auditorium scenes come from the supplied photographs. They do not establish that a previous EDU MindSet or UnitED event took place.

See `DESIGN.md` for current tokens and components, `docs/v4-direction.md` for the rationale, and `docs/v4-research-notes.md` for linked primary references. The new collage uses native SVG/CSS and the existing raster photographs, font, and lightweight script. It adds no raster texture, font family, or runtime drawing library. Test evidence belongs in the verification and handoff records; no earlier version's performance score certifies V4.

The phone UnitED composition uses a two-row grid: wordmark first, subtitle and dialogue drawing second. This is a concrete example of reflow solving a collision rather than shrinking every element.
